Executive Hunter TEST

Privacy policy

Executive Hunter TEST is a personal desktop job-search application used by its account owner. This notice describes its current local TEST implementation.

Google data accessed

With the owner's Google authorization, the application verifies the account's email address and reads job-alert messages using Gmail read-only access. Google grants mailbox-wide read access; normal application searches are restricted by job-alert sender and subject filters. Message content is processed to extract job cards and public links. Gmail message identifiers are retained to avoid processing duplicates. The application does not request permission to delete or modify mailbox messages.

A separate Gmail send authorization can be stored for optional applications. Sending requires the owner's review of the opportunity, recipient, subject, message and chosen CV. The search workflow never sends applications. The central sending switch is currently disabled in TEST.

Storage and sharing

  • Job records, source links, CV files, drafts, account-connection status and application history are stored on the owner's computer. Selected job records and public links are synchronized to the owner's designated TEST Google Sheet.
  • Google OAuth credentials and refresh tokens are kept in the current Windows user's Credential Manager. They are not placed in the public information site or development archives.
  • Local backups contain personal job-search records and CV files, so they must remain private. The information website contains none of these records.
  • If the owner explicitly approves a particular application, Google Gmail processes the message and CV and delivers them to the displayed recipient.
  • Public internet searches use professional job-search terms. The local search workflow does not send the owner's CV, mailbox content or contact details to the search provider or to a paid AI model.

Limited use

Google API data is handled under the Google API Services User Data Policy, including the Limited Use requirements.

Google user data is used to provide the requested personal job-search and reviewed-application functions. The application does not sell Google user data, use it for advertising, or use it to train generalized AI models. The current local workflow does not provide third-party human access to mailbox content.

Retention and control

Local records, drafts, CVs and backups remain until the owner removes them. Stopping the application stops its local work. The owner can revoke Google authorization from the Google Account permissions page. Revocation does not automatically delete local backups, sent messages, or rows already saved in Google Sheets; these are managed separately by the owner. Credentials are protected by Windows Credential Manager; other local files rely on the computer's access and disk protections.

This information website

GitHub Pages hosts these static information pages. GitHub records visitors’ IP addresses for security purposes under its privacy statement.

These pages contain no upload form, login flow, analytics script, or application API key. The selected hosting provider may process ordinary website access logs under its own privacy policy. The application is not accessible through this website.

Contact and changes

The owner can contact the app maintainer through the support email shown on the Google consent screen. This notice must be updated if the application's data practices change.
